What just happened

Honest limits of this page

  • Objects here are 1 cell (8 for a “huge” one). Real objects have headers, padding and sizes from 16 bytes to megabytes, which makes fragmentation considerably worse than shown.
  • Pause length is computed, not measured: pause = 1.0 + 0.02 × (objects scanned) + 0.05 × (cells copied) + time-to-safepoint in model milliseconds. Real pauses depend on cores, cache behaviour, heap residency and much else.
  • Marking here is a simple worklist. Real collectors mark on many threads with work-stealing queues and mark bitmaps.
  • There is no JIT, no escape analysis, no TLAB, no weak references, no class unloading, no metaspace, and no operating system. Each of those changes real behaviour; stage 13 of the README lists how.
  • The G1 and ZGC models here capture the idea — region selection, concurrent marking, concurrent relocation with forwarding — not the real implementations.
