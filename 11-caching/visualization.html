The Cache Bench

A cache is a small, fast box that remembers answers so the slow database behind it doesn't have to keep re-answering. It works because a few keys are asked for constantly. It gets hard because the answers it remembers can quietly stop being true, and because the box is too small to keep everything — so something must be thrown out. Press Send 25 requests and watch both problems appear on their own.
