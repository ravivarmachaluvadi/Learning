The Compounding Loop

Every finished task teaches you something. Almost all of it evaporates when the session ends. This page runs two versions of the same team through the same fourteen tasks — one that writes down what it learns in a way a machine can find again, and one that doesn't — so you can watch the difference appear, and then watch it break.
