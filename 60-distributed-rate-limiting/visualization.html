    Predict, then run

    Pick a scenario. Each one asks you to commit to an answer before it runs — that is where the learning is.

    This is a simulation of the architecture, not of any real product. The hop to the store is a control: 3 ms is a loaded in-region store, 1 ms a healthy one, 10 ms+ cross-availability-zone. The counter is a token bucket with burst equal to the limit, which is why a healthy design can briefly show slightly more than 60 — burst is permission to exceed the average rate.
