Minting unique short codes without a bottleneck

Three strategies mint the same number of short codes. Watch what each one has to phone home for. Naive Counter asks a shared counter for permission on every single mint. Random + Retry guesses a code and only finds out it collided after asking. Block Allocation asks once, then mints hundreds of codes locally before asking again.

Scaled down on purpose: this demo uses a keyspace of just 5,000 codes so collisions actually happen on screen. A real 7-character base62 keyspace holds ≈3.52 trillion codes — the README's §8 table works the real collision math at production scale. Only the mechanism here is real; the corpus size is a teaching model.
